# builin 品牌识别规范

> 域名即品牌。`builin` = built-in 缺一个 t——这个缺口就是品牌的独占资产。

---

## 1. 品牌核心

| 维度 | 内容 |
|---|---|
| 品类 | 自托管 AI 网关 |
| 定位 | **AI, built in.** 把所有大模型内置进你现有的工具链与产品 |
| 目标受众 | 主：独立开发者 / 中小技术团队（自建 AI 能力）；次：企业平台组（统一接入、成本与审计）；评估者：CTO / 技术负责人 |
| 核心价值 | ① Built-in 改两个设置，不改工作流 ② One key 一把 key、一份账单、一条日志 ③ Own your stack 数据、成本、可用性自持有 |
| 品牌性格 | 克制、工程、可靠、清晰——基础设施，不是「炫酷 AI」 |
| 叙事并行 | 词义讲 built-in（内嵌），字形细节讲 gateway（方点 = 节点） |

**Tagline**：英文 `built in. one key.` / 中文「内置于你的栈，一把 key 全通。」

## 2. 标识系统

三件套，全部单色、可缩放、无渐变。

### 2.1 主字标（Logotype）
- 文件：`assets/builin-logotype.svg`
- 构造：几何大写，直角笔画，统一骨宽 14u，字高 104u，字距 24u，全平端
- 签名细节：**N 的斜切**（与旧 N 标记同源）+ 全平端；built-in 隐喻由模块标承担
- 用法：网站顶栏、文档页眉、线下主视觉
- 最小尺寸：字高 **16px**（数字）/ **8mm**（印刷）

### 2.2 字母标（Monogram）
- 文件：`assets/builin-monogram.svg`
- 构造：主字标 b 抽出，置于 44% 圆角方形容器（squircle）
- 用法：App 图标、社交头像、favicon（32px 以上）
- 最小尺寸：**24px**

### 2.3 模块标（Module mark）
- 文件：`assets/builin-module.svg`
- 构造：外框 + 内嵌方块 = built-in 单元，可作水印、印章、装饰系统
- 用法：辅助图形、加载态、包装贴纸；**不单独替代品牌名**

### 2.4 净空与比例
- 净空 = 字标 **x 高**，四周等距，任何元素不得进入
- 横向 lockup：字标左对齐，右侧可接产品名（如 builin Gateway），间距 = 0.5x
- 禁止：渐变、描边、阴影、旋转、拉伸、压花底、彩色进标识

## 3. 色彩

| 角色 | 色值 | 用途 |
|---|---|---|
| Ink | `#0A0A0A` | 标识、标题、主按钮（深色模式下反转为 Paper） |
| Paper | `#FFFFFF` | 底色、反白标识 |
| Muted | `#666666` | 辅助正文 |
| Hairline | `#E3E3E3` | 分割线、描边、网格 |
| Signal | `#0F6E56` | 在线 / 成功 / 点缀（**不进标识**） |
| Alert | `#E24B4A` | 告警 / 危险（**不进标识**） |

原则：**品牌 = 单色系统**。彩色只表达状态，永远不涂在 logo 上。深浅两套：Ink on Paper / Paper on Ink。

## 4. 字体

| 层级 | 字体 | 字号 | 用途 |
|---|---|---|---|
| Display | Sora Semibold | 68px / lh 1.02 / ls -0.03em | 主标题（中文回退系统黑体） |
| Title | Sora Semibold | 44px / lh 1.08 / ls -0.025em | 区块标题 |
| Body | 系统无衬线 | 18px / lh 1.62 | 正文 |
| UI | 系统无衬线 Medium | 14–15px | 按钮、导航 |
| Mono | 等宽（JetBrains Mono / ui-monospace） | 13.5px | 终端、代码、配额数字 |

字标本身是 **SVG 路径**，不依赖任何字体文件，线上线下像素级一致。

---

## 5. 构图原则

1. **8pt 网格**：所有间距、尺寸对齐到 8 的倍数
2. **留白节奏**：以字标 x 高为单位（1x 净空 / 2x 段距 / 3x 章距）
3. **左对齐**为主，居中仅用于 hero 与封面
4. **hairline 分割**，不用色块堆层次
5. **一点饱和**：每屏最多一处彩色（状态点 / 强调按钮）

## 6. 应用规范

| 场景 | 资产 | 规格 |
|---|---|---|
| 网站顶栏 | 主字标 | 高 18px，Ink / 反白随主题 |
| Favicon | 字母标 | 32px / 16px（16px 用简化 b） |
| App 图标 | 字母标 | 512×512 母版，圆角 22% |
| 社交头像 | 字母标 | 400×400 |
| 社交封面 | 主字标 + tagline | 字标左，净空 ≥ 2x |
| 名片 / 印刷 | 主字标 | 单色（专黑或专白），最小 8mm 字高 |
| 周边 / 贴纸 | 模块标 | 单色，可放大 |
| 邮件签名 | 主字标 | 高 24px，链接回站点 |
| 文档 / PDF | 主字标 | 页眉左上，高 16px |
| 视频角标 | 字母标 | 24px，右下，80% 不透明度 |

**线下印刷**：Pantone 黑 6 C 或 专白，纸张本白（非纯白）更显克制。

## 7. 命名用法

| 语境 | 写法 |
|---|---|
| 字标 / Logo | **BUILIN**（全大写，SVG 构造字形） |
| 正文首次 | builin |
| 正文后续 | builin / 它 |
| 产品全称 | builin Gateway（仅 title、文档封面） |
| 代码 / 配置 | `builin`（小写，无空格） |
| 中文语境 | 布林（音译，仅口语；书面保持 builin） |
| 禁止 | Builin AI 工厂 / Builin智能 / 正文与标题混用大小写 |

勾选 = 保留，取消勾选 = 计划移除。带锁的是主链路，动不了。备注会自动保存。
倍率制计价ModelRatioP0 · 主链路
按 token 数 × 倍率算钱，最主流的计价方式
示例输入 1000 token × 0.001 = 1 额度
影响关掉则无法按量计费
预扣与结算PreConsumedQuotaP0 · 主链路
先扣一笔，实际用完多退少补
示例先扣 500，实际 320，退回 180
影响关掉则可能超额透支部
固定价（按次）ModelPriceP1 · 建议保留
每次调用一口价，优先于倍率
示例每次 $0.04，不看 token
影响不选则图片类模型只能按倍率估，不准
阶梯表达式计费tiered_exprP2 · 看需求
按 token 区间或字段写表达式定价
示例前 32k 一个价，超出部分加倍
影响不选则长上下文模型只能一刀切
缓存计价CacheRatioP1 · 建议保留
缓存命中的读/写单独定价
示例缓存读 0.1 倍，写 1.25 倍
影响不选则缓存命中仍按全价扣，用户觉得贵
图片/音频计价ImageRatioP2 · 看需求
多模态输入的单独倍率
示例一张图按 85 token 折算
影响不选则多模态调用计费失真
分组倍率GroupRatioP1 · 建议保留
在模型单价上再乘一次，做会员折扣
示例default 1.0，vip 0.9
影响不选则所有用户一个价
额度单位与货币显示QuotaPerUnitP1 · 建议保留
额度换算成钱的口径，以及按钱还是按 token 展示
示例1 单位 = $0.002
影响改错则历史金额显示全变
价格同步ratio_syncP1 · 建议保留
从公共价目表拉价格并与本地比对
示例一键发现 12 个模型涨价
影响不选则上游调价你只能人工发现
价格入口归一到「模型」页/models §pricingP1 · 建议保留
模型与价格同一页，行内改价，不再藏在设置三级
示例列表里点价格单元格直接改
影响不选则改价要跨 2 个一级入口、3 层导航
工具调用计价task_pricingP3 · 建议移除
按工具/异步任务单独计价
示例一次视频生成收固定额度
影响不选则这类任务按 token 算会亏
倍率对外公开ExposeRatioEnabledP3 · 建议移除
是否把内部倍率暴露给普通用户
示例用户能看到 0.5 倍率
影响公开等于把定价策略摊开

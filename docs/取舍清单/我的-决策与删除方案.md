## 三、三处需要你确认的分歧

### 分歧 1 · 第 14 项「数据导出」名字是错的

清单里写的是「数据导出 · DataExportEnabled」，但 `DataExportEnabled` 实际控制的是**统计看板的总开关**：

```go
// model/usedata.go:41
func UpdateQuotaData() {
	for {
		if common.DataExportEnabled {
			common.SaveQuotaDataCache()   // logs → quota_data 预聚合
		}
		time.Sleep(...)
	}
}
```

界面上的标签也是 **"Enable Data Dashboard"**（系统设置 → 内容 → 数据看板），不是「导出」。

- 删了它 = **统计看板所有图表变空**
- 你在第 2 项明确保留了「统计看板」，两者直接冲突

**真正的 CSV 导出**是另一个东西：`features/usage-logs/components/usage-logs-export-button.tsx`，纯前端把当前表格导成 CSV，没有后端开关，属于「用量日志」页面的一部分（第 15 项，你保留了）。

**我的建议**：第 14 项按「保留」处理，把这一项从删除清单里划掉。如果你真正想删的是「用量日志页的导出 CSV 按钮」，那是 1 个文件的事，告诉我一声即可。

### 分歧 2 · 订阅套餐保留，但支付只剩 Epay —— 可行

原方案（B1）把订阅整栈下线 −9,000 行，你选择保留，这没问题。需要确认的是**订阅只剩 Epay 后还能不能走通**：

- `controller/subscription_payment_epay.go`（220 行）**存在**，Epay 订阅支付是独立实现
- 删掉 Stripe / Creem / Waffo-Pancake 的订阅支付文件后，订阅购买流程只走 Epay，功能完整

所以「订阅保留 + 支付收敛到 Epay」是自洽的，不冲突。

**副作用**：`/api/status` 里的订阅相关字段、钱包页的订阅套餐卡片都保留，只是支付方式从 5 个变 1 个。

### 分歧 3 · 「访问令牌」删的是用户自建令牌，不是登录态

这两者在前端共用一个字段名 `auth.accessToken`，容易误伤：

| | 是什么 | 存哪 | 处理 |
|---|---|---|---|
| **登录会话令牌** | 登录后签发的控制台凭证，所有后台 API 都靠它 | `auth-store` / `auth_flows` | **必须保留** |
| **用户自建访问令牌** | 用户在「安全」页手动创建的、带 scope 的脚本令牌 | `user_access_tokens` 表 | **本次删除** |

`middleware/auth.go` 的 `authenticateDashboardRequest` 返回 `useAccessToken bool`——两种凭证走同一个 `Authorization: Bearer` 头。删除时只摘掉「用户自建令牌」这条分支，登录态那条要原样保留。

生产 `user_access_tokens` 为 0 行，删了不影响任何人。

**但有一个隐藏钉**：`controller/access_token.go` 末尾藏着 `GetAuditLogs`（45 行），服务的正是你保留的 `/api/audit` 和 `/api/audit/self`。不能整文件删，要先抽出来。

## 五、隐藏耦合清单（按「踩了才发现」排序）

1. **`GetAuditLogs` 藏在 `controller/access_token.go`** —— 审计日志是保留项，整文件删会静默丢失功能。
2. **`middleware/auth.go` 一个函数管两种凭证** —— 删访问令牌不能顺手删 `authenticateDashboardRequest`，登录态在里面。
3. **`IsPaymentComplianceConfirmed` 有 8 处引用** —— 删支付厂商时它必须留着，兑换码、订阅、用户设置都靠它开闸。
4. **`DataExportEnabled` 是看板数据源** —— 名字骗人，删了看板空。
5. **订阅与支付共用 `option/waffo-pancake/subscription-product*` 路由** —— 删 Waffo-Pancake 时订阅侧要留 Epay 版本。
6. **`aff_*` 四个列在 `userQuotaColumns` 里**（`model/main.go:279`）—— 删代码时要同步这行，否则额度更新语句引用不存在的字段。
7. **`users-columns.tsx` 的邀请人列依赖 `inviter_id`** —— 删后端字段前先摘前端，否则类型检查红。
